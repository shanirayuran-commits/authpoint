First, you need to register an OAuth application to get a Client ID and Secret.

Grant Consent & Get Code

Follow these steps to get your authorization code:

  1. Click "Open in Browser" button in Step 2 to generate authorization URL
  2. You'll be redirected to the consent screen
  3. Click "Allow Access" to grant permission
  4. The callback page will show your Authorization Code
  5. Click "Continue to Token Exchange" on the callback page
  6. Fields below will be auto-populated
